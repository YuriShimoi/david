Referência da API

Gerada a partir das anotações em scripting/LuaApi.cpp e sdk/david_plugin.h, então sempre bate com o código. Cores são inteiros (use david.rgba e david.channels); os índices de camada começam em 1.

Lua: david

david.apiVersion

david.apiVersion -> integer

A versão da API (1). O "api" do mod.json não pode ser maior.

david.rgba

david.rgba(r, g, b [, a]) -> color

Empacota canais de 0-255 em uma cor. O alfa é 255 por padrão. As cores são inteiros simples.

local red = david.rgba(255, 0, 0)

david.channels

david.channels(color) -> r, g, b, a

Desempacota uma cor em canais de 0-255.

local r, g, b, a = david.channels(img:get(x, y))

david.log

david.log(...)

Escreve uma linha no log do mod (Configurações > Mods). print faz o mesmo.

david.effect

david.effect{ id, name, category, params, run, dim }

Registra um efeito. params é uma lista de { id, label, type, min, max, default, choices, showIf } (tipos: float, int, bool, choice, color, text, curve); o David monta a caixa de diálogo, mostra a prévia ao vivo, e a CLI pode executá-lo pelo id. run(img, p) recebe uma Image e os valores por id. A janela atrás da caixa de diálogo permanece como está para que a prévia possa ser avaliada; dim = true a escurece como as outras caixas de diálogo.

david.effect{ id = "darken", name = "Darken", params = { { id = "amount", type = "int", max = 100, default = 50 } }, run = function(img, p) ... end }

david.command

david.command{ id, name, menu, params, run }

Registra um comando no menu Mods (menu = "Mods/Submenu" o aninha). Com params (a mesma lista de david.effect), o David primeiro pede os valores em uma caixa de diálogo. run(doc, p) edita o Document; tudo o que ele altera é uma única etapa de desfazer, e um erro desfaz tudo.

david.command{ id = "flip-names", name = "Uppercase Layer Names", run = function(doc) for i = 1, doc:layerCount() do local l = doc:layer(i); l.name = l.name:upper() end end }

david.window

david.window{ id, title, kind, menu, width, height, draw }

Registra uma janela. kind = "tool" (padrão) acopla como Camadas e Histórico, ou flutua quando Configurações > Aparência tem janelas flutuantes; kind = "dialog" flutua sobre a tela como as Configurações. Ela aparece no menu Mods (menu = "Mods/Submenu" a aninha) e mantém o estado aberto/fechado entre sessões. draw(ui, doc) é executado a cada quadro enquanto ela está aberta: monte-a com os widgets de Ui e guarde os valores em variáveis do próprio mod. As edições no documento feitas em uma chamada de draw são uma única etapa de desfazer com o nome da janela, então edite ao pressionar um botão, e não enquanto um controle deslizante se move.

david.window{ id = "info", title = "Canvas Info", draw = function(ui, doc) ui:text(doc.width .. " x " .. doc.height) end }

david.openWindow

david.openWindow(id) / david.closeWindow(id)

Abre ou fecha uma das janelas do mod, por exemplo uma caixa de diálogo a partir de um botão em uma janela de ferramenta.

if ui:button("Options...") then david.openWindow("options") end

david.tool

david.tool{ id, name, key, ink }

Registra uma ferramenta de pintura: o traço livre e o pincel redondo do Pincel, com a sua tinta. ink(x, y, before, color) retorna a nova cor de um pixel (ou nil para deixá-lo); o resultado é misturado conforme a cobertura do pincel. key é uma letra única opcional. As ferramentas aparecem após reiniciar.

david.tool{ id = "checker", name = "Checker Brush", ink = function(x, y, before, color) if (x + y) % 2 == 0 then return color end end }

david.image

david.image -> Document

Em um script executado pela CLI (--script), a imagem sendo processada. As edições vão para a saída.

david.args

david.args -> { name = value }

Em um script da CLI, os pares --arg nome=valor, como strings.

local size = tonumber(david.args.size or "8")

Lua: Image

Image.width

img.width -> integer

Largura da área em que o efeito é executado (os limites da seleção mais a margem do efeito).

Image.height

img.height -> integer

Altura da área.

Image.x

img.x, img.y -> integer

Posição, na imagem, do pixel do canto superior esquerdo da área, para padrões que precisam se alinhar ao longo da imagem.

Image:get

img:get(x, y) -> color

O pixel antes do efeito (0 fora da área). As coordenadas são relativas à área, a partir de 0.

local c = img:get(x, y)

Image:set

img:set(x, y, color)

Escreve um pixel do resultado. A seleção ainda recorta o que chega à camada.

img:set(x, y, david.rgba(255, 0, 0))

Lua: Document

Document.width

doc.width, doc.height -> integer

O tamanho da imagem em pixels.

Document.primary

doc.primary, doc.secondary -> color

As cores primária e secundária.

Document.palette

doc.palette -> { color, ... }

A paleta atual, em ordem (uma cópia; alterar a tabela não muda nada).

Document.activeLayer

doc.activeLayer -> integer

Índice da camada ativa; 1 é a camada de baixo.

Document:layerCount

doc:layerCount() -> integer

Document:layer

doc:layer(index) -> Layer

A camada no índice (1 = a de baixo); sem índice, a camada ativa.

local top = doc:layer(doc:layerCount())

Document:addLayer

doc:addLayer(name) -> Layer

Adiciona uma camada vazia acima da ativa e a torna ativa.

Document:deleteLayer

doc:deleteLayer(index) -> boolean

Exclui uma camada; a última não pode ser excluída.

Document:selected

doc:selected(x, y) -> integer 0-255

O quanto o pixel está selecionado; 255 em todo lugar quando nada está selecionado.

Document:selectionBounds

doc:selectionBounds() -> x, y, w, h | nil

A caixa delimitadora da seleção, ou nil quando nada está selecionado.

Document:frameCount

doc:frameCount() -> integer

Quantos quadros de animação o documento tem (1 para uma imagem estática).

Document.activeFrame

doc.activeFrame -> integer (read and write)

O quadro em que as camadas são lidas e escritas; 1 é o primeiro. Definir esse valor move para aquele quadro.

for f = 1, doc:frameCount() do doc.activeFrame = f; doc:applyEffect("invert-colors") end

Document.fps

doc.fps -> number (read and write)

Quadros por segundo para os quadros sem duração própria (1-60).

Document:frameDuration

doc:frameDuration(frame) -> integer

Por quanto tempo o quadro é exibido, em ms (sua própria duração ou a da taxa de quadros).

Document:setFrameDuration

doc:setFrameDuration(frame, ms)

Dá ao quadro uma duração própria; 0 volta à taxa de quadros.

Document:addFrame

doc:addFrame([kind]) -> integer

Adiciona um quadro depois do ativo e o torna ativo: "empty" (o padrão), "copy" ou "linked" (compartilha as imagens do quadro ativo). Retorna o número dele.

local f = doc:addFrame("copy")

Document:deleteFrame

doc:deleteFrame(frame) -> boolean

Exclui um quadro; o último não pode ser excluído.

Document.tags

doc.tags -> { { name, from, to, direction }, ... }

As tags de quadros (uma cópia). direction é "forward", "reverse" ou "pingpong".

Document:applyEffect

doc:applyEffect(id [, params])

Executa um efeito (nativo ou de um mod) na camada ativa dentro da seleção, como parte da etapa de desfazer do comando.

doc:applyEffect("gaussian-blur", { radius = 4 })

Lua: Layer

Layer.name

layer.name -> string (read and write)

O nome da camada. Alterá-lo faz parte da etapa de desfazer do comando.

Layer.visible

layer.visible -> boolean (read and write)

Layer.opacity

layer.opacity -> integer 0-255 (read and write)

Layer.blend

layer.blend -> string (read and write)

O id do modo de mesclagem: normal, multiply, additive, color-burn, color-dodge, reflect, glow, overlay, difference, negation, lighten, darken, screen, xor.

layer.blend = "multiply"

Layer:get

layer:get(x, y) -> color

Um pixel da camada (0 fora da imagem).

Layer:set

layer:set(x, y, color)

Escreve um pixel. Ignora a seleção; verifique doc:selected(x, y) para respeitá-la.

if doc:selected(x, y) > 0 then layer:set(x, y, c) end

Lua: Ui

Ui:text

ui:text(text) / ui:muted(text)

Uma linha de texto; muted é a cor mais apagada das dicas.

ui:text("Layers: " .. doc:layerCount())

Ui:header

ui:header(text)

Um cabeçalho de seção (em maiúsculas, apagado), como os das Configurações.

Ui:separator

ui:separator() / ui:spacing() / ui:sameLine()

Uma linha atravessando a janela, um pequeno espaço vertical, ou o próximo widget na mesma linha do anterior.

Ui:button

ui:button(label [, width]) -> pressed

Um botão; true no quadro em que foi clicado. width em pontos; -1 preenche a linha.

if ui:button("Clear") then doc:layer():set(0, 0, 0) end

Ui:checkbox

ui:checkbox(label, value) -> value, changed

Uma caixa de seleção. Guarde o valor em uma variável do mod e passe-o de volta a cada vez.

snap = ui:checkbox("Snap", snap)

Ui:slider

ui:slider(label, value, min, max [, step]) -> value, changed

Um controle deslizante em barra com campo numérico, como nas janelas de efeito. step arredonda o valor (padrão 1; 0.01 para frações).

size = ui:slider("Size", size, 1, 64)

Ui:choice

ui:choice(label, index, { name, ... }) -> index, changed

Uma lista suspensa; o índice começa em 1.

mode = ui:choice("Mode", mode, { "Add", "Replace" })

Ui:color

ui:color(label, color) -> color, changed

Uma amostra de cor que abre um seletor.

tint = ui:color("Tint", tint)

Ui:input

ui:input(label, text) -> text, changed

Um campo de texto.

prefix = ui:input("Prefix", prefix)

Ui:width

ui:width() -> number

A largura que sobra na linha atual, em pontos.

Ui:close

ui:close()

Fecha a janela depois deste quadro (o menu ou david.openWindow a abre de novo).

ABI C (plugins nativos)

De sdk/david_plugin.h. Os pixels são RGBA8 sem pré-multiplicação, vermelho no byte baixo, linhas de cima para baixo.

DAVID_API_VERSION

#define DAVID_API_VERSION 1

A versão da API que este cabeçalho descreve. david_plugin_init recebe a versão do host; retorne 0 para recusar um host mais antigo.

david_image

typedef struct { int width, height; uint32_t* pixels; } david_image

Uma imagem RGBA8: width * height pixels, alfa direto (não pré-multiplicado), vermelho no byte baixo, linhas de cima para baixo.

uint32_t c = img->pixels[y * img->width + x]; uint8_t alpha = c >> 24;

david_effect

typedef struct { id, name, category, params_json, run, user } david_effect

Um efeito. params_json é um array JSON de parâmetros, cada um {"id", "label", "type" (float, int, bool, choice, color), "min", "max", "default", "choices"}; o David monta a caixa de diálogo a partir dele, e a CLI e o Lua usam os mesmos ids. run recebe os limites da seleção como src (dst começa como uma cópia) e os valores como um objeto JSON; retorna 0 em caso de sucesso.

static int invert(void* user, const david_image* src, david_image* dst, const char* values) { for(int i = 0; i < src->width * src->height; i++) dst->pixels[i] = src->pixels[i] ^ 0x00FFFFFFu; return 0; }

david_format

typedef struct { ext, name, load, save, user } david_format

Um formato de arquivo por extensão. load decodifica bytes em out (out->pixels alocado com host->alloc); save codifica img em *bytes (alocado com host->alloc). Qualquer um dos dois pode ser NULL. Ambos retornam 0 em caso de sucesso.

static int load(void* user, const uint8_t* bytes, size_t size, david_image* out) { out->width = 1; out->height = 1; out->pixels = host->alloc(4); out->pixels[0] = 0xFF0000FFu; return 0; }

david_host

typedef struct { api_version, alloc, free, register_effect, register_format, log } david_host

O que o David fornece ao plugin. As funções de registro copiam o que precisam, então as structs passadas a elas podem ficar na pilha; os ponteiros de função e os dados do usuário devem continuar válidos enquanto o plugin estiver carregado.

david_host.alloc

void* alloc(size_t bytes)

Memória que o David libera depois: pixels carregados e bytes salvos.

david_host.free

void free(void* p)

Libera memória de alloc que o plugin não devolveu.

david_host.register_effect

int register_effect(const david_effect* effect)

Adiciona um efeito aos menus, à CLI e ao Lua. Retorna 0 em caso de sucesso.

host->register_effect(&my_effect);

david_host.register_format

int register_format(const david_format* format)

Adiciona um formato de arquivo a Abrir, Salvar como e à CLI. Retorna 0 em caso de sucesso.

host->register_format(&my_format);

david_host.log

void log(const char* message)

Escreve uma linha no log do mod (Configurações > Mods mostra as últimas linhas).

david_plugin_init

DAVID_PLUGIN_EXPORT int david_plugin_init(const david_host* host)

A única função que um plugin exporta. Registre tudo aqui; retorne 0 em caso de sucesso, qualquer outro valor para falhar o carregamento (o erro aparece em Configurações > Mods).

DAVID_PLUGIN_EXPORT int david_plugin_init(const david_host* host) { return host->register_effect(&my_effect); }
