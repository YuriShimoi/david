API reference

Generated from the annotations in scripting/LuaApi.cpp and sdk/david_plugin.h, so it always matches the code. Colors are integers (use david.rgba and david.channels); layer indices start at 1.

Lua: david

david.apiVersion

david.apiVersion -> integer

The API version (1). mod.json's "api" must not be higher.

david.rgba

david.rgba(r, g, b [, a]) -> color

Packs 0-255 channels into a color. Alpha defaults to 255. Colors are plain integers.

local red = david.rgba(255, 0, 0)

david.channels

david.channels(color) -> r, g, b, a

Unpacks a color into 0-255 channels.

local r, g, b, a = david.channels(img:get(x, y))

david.log

david.log(...)

Writes a line to the mod's log (Settings > Mods). print does the same.

david.effect

david.effect{ id, name, category, params, run, dim }

Registers an effect. params is a list of { id, label, type, min, max, default, choices, showIf } (types: float, int, bool, choice, color, text, curve); David builds the dialog, previews live, and the CLI can run it by id. run(img, p) gets an Image and the values by id. The window behind the dialog stays as is so the preview can be judged; dim = true darkens it like other dialogs.

david.effect{ id = "darken", name = "Darken", params = { { id = "amount", type = "int", max = 100, default = 50 } }, run = function(img, p) ... end }

david.command

david.command{ id, name, menu, params, run }

Registers a command under the Mods menu (menu = "Mods/Submenu" nests it). With params (the same list as david.effect) David first asks for them in a dialog. run(doc, p) edits the Document; everything it changes is one undo step, and an error undoes it all.

david.command{ id = "flip-names", name = "Uppercase Layer Names", run = function(doc) for i = 1, doc:layerCount() do local l = doc:layer(i); l.name = l.name:upper() end end }

david.window

david.window{ id, title, kind, menu, width, height, draw }

Registers a window. kind = "tool" (default) docks like Layers and History, or floats when Settings > Appearance has floating windows; kind = "dialog" floats over the canvas like Settings. It's listed in the Mods menu (menu = "Mods/Submenu" nests it) and keeps its open state between sessions. draw(ui, doc) runs every frame while it's open: build it with the Ui widgets, keep values in the mod's own variables. Document edits made in one draw call are one undo step named after the window, so edit on a button press rather than while a slider moves.

david.window{ id = "info", title = "Canvas Info", draw = function(ui, doc) ui:text(doc.width .. " x " .. doc.height) end }

david.openWindow

david.openWindow(id) / david.closeWindow(id)

Opens or closes one of the mod's windows, e.g. a dialog from a button in a tool window.

if ui:button("Options...") then david.openWindow("options") end

david.tool

david.tool{ id, name, key, ink }

Registers a painting tool: the freehand stroke and round brush of the Paintbrush, with your ink. ink(x, y, before, color) returns the new color of a pixel (or nil to leave it); the result is mixed in by the brush's coverage. key is an optional single letter. Tools appear after a restart.

david.tool{ id = "checker", name = "Checker Brush", ink = function(x, y, before, color) if (x + y) % 2 == 0 then return color end end }

david.image

david.image -> Document

In a script run by the CLI (--script), the image being processed. Edits go to the output.

david.args

david.args -> { name = value }

In a CLI script, the --arg name=value pairs, as strings.

local size = tonumber(david.args.size or "8")

Lua: Image

Image.width

img.width -> integer

Width of the area the effect runs on (the selection's bounds plus the effect's margin).

Image.height

img.height -> integer

Height of the area.

Image.x

img.x, img.y -> integer

Image position of the area's top-left pixel, for patterns that must line up across the image.

Image:get

img:get(x, y) -> color

The pixel before the effect (0 outside the area). Coordinates are relative to the area, from 0.

local c = img:get(x, y)

Image:set

img:set(x, y, color)

Writes a pixel of the result. The selection still clips what reaches the layer.

img:set(x, y, david.rgba(255, 0, 0))

Lua: Document

Document.width

doc.width, doc.height -> integer

The image size in pixels.

Document.primary

doc.primary, doc.secondary -> color

The primary and secondary colors.

Document.palette

doc.palette -> { color, ... }

The current palette, in order (a copy; changing the table changes nothing).

Document.activeLayer

doc.activeLayer -> integer

Index of the active layer; 1 is the bottom layer.

Document:layerCount

doc:layerCount() -> integer

Document:layer

doc:layer(index) -> Layer

The layer at index (1 = bottom); without an index, the active layer.

local top = doc:layer(doc:layerCount())

Document:addLayer

doc:addLayer(name) -> Layer

Adds an empty layer above the active one and makes it active.

Document:addVectorLayer

doc:addVectorLayer(name) -> Layer

Adds an empty vector layer above the active one and makes it active.

local v = doc:addVectorLayer("Shapes"); v:addObject({ kind = "ellipse", x = 0, y = 0, w = 40, h = 40, fill = doc.primary })

Document:deleteLayer

doc:deleteLayer(index) -> boolean

Deletes a layer; the last one can't be deleted.

Document:selected

doc:selected(x, y) -> integer 0-255

How much the pixel is selected; 255 everywhere when nothing is selected.

Document:selectionBounds

doc:selectionBounds() -> x, y, w, h | nil

The selection's bounding box, or nil when nothing is selected.

Document:frameCount

doc:frameCount() -> integer

How many animation frames the document has (1 for a still image).

Document.activeFrame

doc.activeFrame -> integer (read and write)

The frame layers are read and written on; 1 is the first. Setting it moves to that frame.

for f = 1, doc:frameCount() do doc.activeFrame = f; doc:applyEffect("invert-colors") end

Document.fps

doc.fps -> number (read and write)

Frames per second for the frames without their own duration (1-60).

Document:frameDuration

doc:frameDuration(frame) -> integer

How long the frame shows, in ms (its own duration, or the frame rate's).

Document:setFrameDuration

doc:setFrameDuration(frame, ms)

Gives the frame its own duration; 0 goes back to the frame rate.

Document:addFrame

doc:addFrame([kind]) -> integer

Adds a frame after the active one and makes it active: "empty" (the default), "copy" or "linked" (shares the active frame's images). Returns its number.

local f = doc:addFrame("copy")

Document:deleteFrame

doc:deleteFrame(frame) -> boolean

Deletes a frame; the last one can't be deleted.

Document.tags

doc.tags -> { { name, from, to, direction }, ... }

The frame tags (a copy). direction is "forward", "reverse" or "pingpong".

Document:applyEffect

doc:applyEffect(id [, params])

Runs an effect (built in or from a mod) on the active layer inside the selection, as part of the command's undo step.

doc:applyEffect("gaussian-blur", { radius = 4 })

Lua: Layer

Layer.name

layer.name -> string (read and write)

The layer's name. Changing it is part of the command's undo step.

Layer.visible

layer.visible -> boolean (read and write)

Layer.opacity

layer.opacity -> integer 0-255 (read and write)

Layer.blend

layer.blend -> string (read and write)

The blend mode id: normal, multiply, additive, color-burn, color-dodge, reflect, glow, overlay, difference, negation, lighten, darken, screen, xor.

layer.blend = "multiply"

Layer:get

layer:get(x, y) -> color

A pixel of the layer (0 outside the image).

Layer:set

layer:set(x, y, color)

Writes a pixel. It ignores the selection; check doc:selected(x, y) to respect it.

if doc:selected(x, y) > 0 then layer:set(x, y, c) end

Layer.isVector

layer.isVector -> boolean

True for a vector layer (objects instead of pixels; Settings > Beta tools > Vector support).

Layer:objects

layer:objects() -> { object, ... }

A vector layer's objects on the active frame, bottom to top, as tables (a copy): id, kind ("path", "rect", "ellipse", "polygon", "text", "group"), name, x, y, w, h, radius, sides, inner, d (path data), text, size, fill and stroke (colors, or false), width, opacity, transform, bounds.

for _, o in ipairs(layer:objects()) do david.log(o.kind .. " " .. o.id) end

Layer:addObject

layer:addObject(fields) -> integer id

Adds an object on top of a vector layer. kind is "rect", "ellipse", "polygon" (x, y, w, h; radius; sides, inner), "path" (d, SVG path data) or "text" (text, font file, size, x, y); fill and stroke are colors (david.rgba) or false, width the line width, transform an SVG transform list.

layer:addObject({ kind = "polygon", x = 10, y = 10, w = 80, h = 80, sides = 5, inner = 0.5, fill = david.rgba(255, 200, 0) })

Layer:setObject

layer:setObject(id, fields) -> boolean

Changes the given fields of an object (the same fields as addObject, but kind); false when there's no such object.

layer:setObject(id, { fill = david.rgba(0, 0, 0), transform = "rotate(45 50 50)" })

Layer:removeObject

layer:removeObject(id) -> boolean

Removes an object from a vector layer.

Layer:svg

layer:svg() -> string

A vector layer's objects as an SVG document.

Layer:addSvg

layer:addSvg(text) -> integer

Adds the objects of an SVG document on top of a vector layer; returns how many.

layer:addSvg('<svg xmlns="http://www.w3.org/2000/svg"><circle cx="20" cy="20" r="10" fill="red"/></svg>')

Lua: Ui

Ui:text

ui:text(text) / ui:muted(text)

A line of text; muted is the dimmer color of hints.

ui:text("Layers: " .. doc:layerCount())

Ui:header

ui:header(text)

A section header (upper case, muted), like the ones in Settings.

Ui:separator

ui:separator() / ui:spacing() / ui:sameLine()

A line across the window, a little vertical space, or the next widget on the same row as the last one.

Ui:button

ui:button(label [, width]) -> pressed

A button; true on the frame it was clicked. width in points; -1 fills the row.

if ui:button("Clear") then doc:layer():set(0, 0, 0) end

Ui:checkbox

ui:checkbox(label, value) -> value, changed

A check box. Keep the value in a variable of the mod and pass it back each time.

snap = ui:checkbox("Snap", snap)

Ui:slider

ui:slider(label, value, min, max [, step]) -> value, changed

A bar slider with a number field, like the effect dialogs. step rounds the value (default 1; 0.01 for fractions).

size = ui:slider("Size", size, 1, 64)

Ui:choice

ui:choice(label, index, { name, ... }) -> index, changed

A drop-down list; index starts at 1.

mode = ui:choice("Mode", mode, { "Add", "Replace" })

Ui:color

ui:color(label, color) -> color, changed

A color swatch that opens a picker.

tint = ui:color("Tint", tint)

Ui:input

ui:input(label, text) -> text, changed

A text field.

prefix = ui:input("Prefix", prefix)

Ui:width

ui:width() -> number

The width left on the current row, in points.

Ui:close

ui:close()

Closes the window after this frame (the menu or david.openWindow opens it again).

C ABI (native plugins)

From sdk/david_plugin.h. Pixels are straight RGBA8, red in the low byte, rows top first.

DAVID_API_VERSION

#define DAVID_API_VERSION 1

The API version this header describes. david_plugin_init gets the host's version; return 0 to refuse an older host.

david_image

typedef struct { int width, height; uint32_t* pixels; } david_image

An RGBA8 image: width * height pixels, straight alpha, red in the low byte, rows top first.

uint32_t c = img->pixels[y * img->width + x]; uint8_t alpha = c >> 24;

david_effect

typedef struct { id, name, category, params_json, run, user } david_effect

An effect. params_json is a JSON array of params, each {"id", "label", "type" (float, int, bool, choice, color), "min", "max", "default", "choices"}; David builds the dialog from it, and the CLI and Lua use the same ids. run gets the selection's bounds as src (dst starts as a copy) and the values as a JSON object; it returns 0 on success.

static int invert(void* user, const david_image* src, david_image* dst, const char* values) { for(int i = 0; i < src->width * src->height; i++) dst->pixels[i] = src->pixels[i] ^ 0x00FFFFFFu; return 0; }

david_format

typedef struct { ext, name, load, save, user } david_format

A file format by extension. load decodes bytes into out (out->pixels allocated with host->alloc); save encodes img into *bytes (allocated with host->alloc). Either may be NULL. Both return 0 on success.

static int load(void* user, const uint8_t* bytes, size_t size, david_image* out) { out->width = 1; out->height = 1; out->pixels = host->alloc(4); out->pixels[0] = 0xFF0000FFu; return 0; }

david_host

typedef struct { api_version, alloc, free, register_effect, register_format, log } david_host

What David gives the plugin. The register functions copy what they need, so the structs passed to them may live on the stack; the function pointers and user data must stay valid while the plugin is loaded.

david_host.alloc

void* alloc(size_t bytes)

Memory David frees later: loaded pixels and saved bytes.

david_host.free

void free(void* p)

Frees memory from alloc that the plugin didn't hand back.

david_host.register_effect

int register_effect(const david_effect* effect)

Adds an effect to the menus, the CLI and Lua. Returns 0 on success.

host->register_effect(&my_effect);

david_host.register_format

int register_format(const david_format* format)

Adds a file format to Open, Save As and the CLI. Returns 0 on success.

host->register_format(&my_format);

david_host.log

void log(const char* message)

Writes a line to the mod's log (Settings > Mods shows the last lines).

david_plugin_init

DAVID_PLUGIN_EXPORT int david_plugin_init(const david_host* host)

The one function a plugin exports. Register everything here; return 0 on success, anything else to fail loading (the error shows in Settings > Mods).

DAVID_PLUGIN_EXPORT int david_plugin_init(const david_host* host) { return host->register_effect(&my_effect); }
