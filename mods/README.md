# Mods
Each mod is a folder with a `mod.json`. Mods here ship with David; your own go in the config folder's `mods/`
(`%APPDATA%\David\mods` on Windows, `~/.config/david/mods` on Linux). The examples are off until you turn them on
in Settings > Mods. The modding guide is `docs/modding/index.html` (Help > Modding guide).
